# Gigi Marquez - IT Portfolio

A clean, responsive, and modern personal IT portfolio website built with HTML5, CSS3, and JavaScript. This project showcases skills in web development, network infrastructure, and featured IT projects.

##  Features

* **Responsive Navigation:** Smooth scroll links to key sections (About, Skills, Portfolio, and Contact).
* **Interactive Skill Bars:** Visual progress bars displaying technical proficiencies in web development and networking.
* **Featured Projects Showcase:** Dedicated card layouts highlighting recent technical work.
* **Contact Form & Info:** Integrated contact details along with an interactive contact form interface.
* **Social Links & Footer:** Full navigation footer with quick links, capability listings, and social platform icons via Font Awesome.

##  Tech Stack

* **Structure:** HTML5
* **Styling:** Custom CSS3
* **Icons:** Font Awesome 6.4.0
* **Scripting:** JavaScript
